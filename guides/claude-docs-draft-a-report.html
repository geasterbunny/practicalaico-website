How to Draft a Report With Claude Docs, Section by Section

Anthropic folded its separate Cowork workspace into ordinary Claude chat and launched a real, editable document tool. Here's how to actually use it instead of copy-pasting chat replies into Word.

What changed on 16 September

Anthropic folded its separate "Cowork" workspace into ordinary Claude chat and launched two new built-in tools alongside it: Claude Docs and Claude Slides. Docs is a real, editable document that lives inside Claude, not a wall of chat text you then have to copy out into Word. You ask for something, Claude opens a document, and you keep talking to refine specific parts of it.

How to start one

Go to claude.ai, or the desktop app, and start a new chat as usual. Ask for a document rather than a chat answer — "write me a one-page project update for my manager" — and Claude opens it as a Doc automatically when the request calls for it. If it doesn't switch over on its own, ask directly: "build this as a document, not a chat reply."

Working on it section by section

The part worth learning is that you don't have to redo the whole thing when one part is wrong. Ask Claude to fix just the second paragraph, or add a section on budget, and it edits that part while leaving the rest untouched. You can also leave a comment on a specific paragraph, the way you would in Word, and Claude responds to that comment directly rather than rewriting the whole document around it.

Getting it out of Claude

When you're happy with it, Docs can be shared as a link — useful if a colleague also has Claude access — or downloaded. Anthropic lists Word and PDF export as part of the feature. Test both before you rely on either for something urgent: a brand-new export feature in its first weeks is exactly the kind of thing that can have formatting rough edges, and you want to find that on your own screen, not after you've sent the file on.

I need a [type of document, e.g. one-page project update] for [audience]. Here's the context: [background info, or paste the source material] It needs to cover: [the 2-4 sections you need] Tone: [e.g. formal, brief, for a non-technical reader] Build this as a Claude Doc, not a chat reply. Once it's drafted, I'll tell you which sections to adjust one at a time.
💡 This week's action

Open Claude and draft something you were going to write in Word anyway — a status update, a short proposal, a set of meeting minutes. Use section-by-section editing instead of asking for a full rewrite each time. That's the whole point of the feature, and running one real task through it is the fastest way to tell whether it belongs in your week.

Who can use it right now

This is rolling out to Pro and Max subscribers first, across web, desktop and mobile, with free and team tiers to follow later — Anthropic hasn't given a firm date for that yet. If you're on a free Claude account, you'll still see the older chat-only experience for now.

Should you switch from Word or Google Docs

Not yet, not fully. Treat Claude Docs as a fast way to get a strong first draft that lives somewhere collaborative, not as your permanent home for a document your whole team needs to track changes on. For now, draft in Claude, then move the finished version into whatever your workplace already uses for version control and sign-off. As the feature matures over the coming months, that advice may well change.

A realistic first task to try

Don't start with your most important document. Pick something lower-stakes but genuinely useful — a weekly status update, a summary of a project for a colleague who's about to go on leave, or a first pass at a proposal you'll heavily edit anyway. Give Claude the same brief you'd give a capable junior colleague: what it's for, who's reading it, and what "done" looks like. The gap between a vague brief and a specific one shows up immediately in how much editing you have to do afterwards.

What happens to work you've already built in Cowork

If you were already using Cowork before the merge, your existing files and chats should carry over into the unified interface rather than disappearing — but if you relied on a specific Cowork workflow for something important, it's worth checking that it still behaves the way you expect in the first week or two after the change, rather than assuming nothing shifted underneath it.
